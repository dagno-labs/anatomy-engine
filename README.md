Anatomy Viewer is an interactive 3D viewer of human anatomy for the web, built with React and Three.js. It renders the BodyParts3D adult male reference model by anatomical system, to show or hide systems, find named structures, separate the model into its pieces and inspect each one. It is in early development, and nothing is published yet.

It is an educational and visual reference. It is not a diagnostic or clinical tool, and it does not replace the judgment of a healthcare professional.
